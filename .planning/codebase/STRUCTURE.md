## Directory Purposes

**Repository Root:**
- Purpose: Notebooks, utilities, and documentation. Organized by pipeline stage (extraction → merge → analysis).
- Contains: Jupyter notebooks (.ipynb), MATLAB scripts (.m), metadata files (README, requirements, .gitignore)
- Key files: `BuildPkl_*.ipynb` (ingestion), `Load Data.ipynb` / `LoadData.m` (reconciliation), `EC_dQdV.m` (feature extraction)

**.planning/codebase/ (GSD analysis):**
- Purpose: Automated documentation generated by GSD planning tools.
- Contains: ARCHITECTURE.md, STRUCTURE.md, and potentially STACK.md, TESTING.md, CONVENTIONS.md, CONCERNS.md
- Key files: Generated by `/gsd-map-codebase` command; consumed by `/gsd-plan-phase` and `/gsd-execute-phase` to inform code generation and refactoring decisions.

**./Data/ (user-provided, not in git):**
- Purpose: Raw HDF5-formatted MATLAB struct files (external, licensed).
- Contains: Three `.mat` files (one per batch); ~9 GB total.
- Key files: `2017-05-12_...`, `2017-06-30_...`, `2018-04-12_...` (download from https://data.matr.io/1/)

**./Figures/ (output, not in git):**
- Purpose: Generated analysis figures.
- Contains: PNG and FIG files produced by `Figure4_mac.m`.
- Key files: `Fig5.png`, `Fig5.fig`, `Fig5_legend.png` (reproducibility validation)

## Naming Conventions

**Files:**

| Pattern | Examples | Purpose |
|---------|----------|---------|
| `BuildPkl_Batch[N].ipynb` | `BuildPkl_Batch1.ipynb` | Stage 1 extraction notebooks; numbered by batch |
| `Load*.ipynb` / `Load*.m` | `Load Data.ipynb`, `LoadData.m` | Stage 2 merge/clean scripts; language-specific variants |
| `EC_d[X]d[Y].m` | `EC_dQdV.m`, `EC_dVdQ.m` | Electrochemistry utilities; `d[X]/d[Y]` notation from mathematics |
| `Figure[N]_*.m` | `Figure4_mac.m` | Paper figure reproduction scripts; numbered by paper figure, suffix for variant (e.g., `_mac`) |

**Directories:**

| Pattern | Examples | Purpose |
|---------|----------|---------|
| `./Data/` | `./Data/2017-05-12_...mat` | Raw licensed data; not in git; user-provided |
| `.planning/codebase/` | `.planning/codebase/ARCHITECTURE.md` | GSD analysis documents; auto-generated |
| `./Figures/` | `./Figures/Fig5.png` | Output directory for analysis plots; not in git |

**Notebook Cell Naming:**

Cells are identified by integer index (0-indexed in Python):
- Cell 0: Imports
- Cell 1: File paths & parameter setup
- Cells 2–N: Processing logic
- Final cells: Serialization/output

Example: `BuildPkl_Batch1.ipynb:cell-5` refers to the cell containing the main extraction loop (lines ~30–60).

**Dictionary/Struct Keys:**

| Key Pattern | Examples | Data Type | Scope |
|-------------|----------|-----------|-------|
| `b[N]c[M]` | `b1c0`, `b2c15`, `b3c42` | Cell ID | Global; N ∈ {1,2,3} (batch), M ∈ {0..47} (cell index) |
| `summary` | Dict/struct field | Aggregated per-cycle data | Per cell |
| `cycles` | Dict/struct field | Per-cycle raw samples | Per cell |
| `[0-9]+` (string keys) | `cycles['0']`, `cycles['100']` | Cycle number | Per cell; cycle data |
| `QD`, `QC`, `IR`, `Tavg`, etc. | Summary fields | Numpy array / column vector | Per cell, per cycle |
| `V`, `I`, `T`, `dQdV`, `t` | Cycle fields | Numpy array | Per cycle, per sample |

## Where to Add New Code

**New Feature (e.g., discharge rate analysis):**
- Primary code: Create a new `.ipynb` notebook at root (e.g., `Analyze_DischargeRate.ipynb`).
- Tests: Add a validation cell at the end (visual plots, summary statistics printed).
- Documentation: Update `CLAUDE.md` with notebook description and dependencies on pickles/struct files.

**New Utility Function (e.g., compute capacity fade per cycle):**
- Implementation: Add a new `.m` file or Python function module at root (e.g., `compute_qd_fade.m` or `utils.py`).
- Convention: Use `EC_` prefix for electrochemistry functions; descriptive function names in snake_case (Python) or camelCase (MATLAB).
- Usage: Import/call from analysis notebooks.
- Documentation: Include header comments with I/O specifications and parameter descriptions.

**New Batch or Dataset:**
- Ingestion: Create `BuildPkl_Batch[N].ipynb` following the template of `BuildPkl_Batch1.ipynb`.
- Schema: Ensure nested dict/struct matches existing `{cycle_life, charge_policy, summary, cycles}` format.
- Merge: Update `Load Data.ipynb` / `LoadData.m` with new batch overlap rules and cell removal indices (hardcoded in batch-specific sections).
- Validation: Add post-merge plot to check for data integrity.

**Test or Validation Script:**
- Location: Add to root directory or new `./tests/` subdirectory if expanding scope.
- Pattern: Use notebooks with visual inspection cells; no unit test framework currently in use.
- Reference: Follow patterns in `BuildPkl_Batch1.ipynb:cells-7,8` (plot discharge capacity, Q-V curves).
