## Data Format & Structure

**Input Data (MATLAB `.mat`):**
- HDF5-based MATLAB files containing battery test metadata and time-series measurements
- Loaded via `h5py` and converted to Python dictionaries via `BuildPkl_Batch*.ipynb`

**Processing Output (Python Pickle):**
- Serialized nested dictionaries with structure:
  ```
  {
    'b1c0': {
      'cycle_life': int,          # Cycles to 80% capacity
      'charge_policy': str,        # Charging protocol
      'summary': {                 # Per-cycle aggregates
        'cycle': ndarray,          # Cycle numbers
        'QD': ndarray,             # Discharge capacity (Ah)
        'QC': ndarray,             # Charge capacity (Ah)
        'IR': ndarray,             # Internal resistance (Ohm)
        'Tmax': ndarray,           # Max temperature (°C)
        'Tavg': ndarray,           # Avg temperature (°C)
        'Tmin': ndarray,           # Min temperature (°C)
        'chargetime': ndarray      # Charging time (hrs)
      },
      'cycles': {                  # Per-cycle detailed measurements
        '0': {
          'I': ndarray,            # Current (A)
          'V': ndarray,            # Voltage (V)
          'Qc': ndarray,           # Charge capacity (Ah)
          'Qd': ndarray,           # Discharge capacity (Ah)
          'Qdlin': ndarray,        # Linearly interpolated discharge
          'T': ndarray,            # Temperature (°C)
          'Tdlin': ndarray,        # Linearly interpolated temperature
          'dQdV': ndarray,         # dQ/dV feature (differential capacity)
          't': ndarray             # Time (seconds)
        },
        ...
      }
    },
    ...
  }
  ```
